已经装好了？打开你的界面

Open your console

NiuxAgent 的界面运行在你自己的电脑上，不在我们的服务器上。如果你正在装有 NiuxAgent 的这台 Windows 电脑上浏览本页，且程序正在运行，点下面的按钮即可直接打开你的界面（首次打开需要输入界面口令，口令在安装时设置、保存在你的电脑上）。

打开本机界面

  • Mac 用户：界面地址每台电脑各不相同，官网无法预先写死。请在你的 Windows 电脑上打开 NiuxAgent，界面里会显示局域网地址和配对码；用 Mac 的浏览器（与电脑连同一个局域网）打开那个地址、输入配对码，Mac 就能当遥控界面使用。
  • 按钮点了没反应或打不开：多半是 NiuxAgent 还没启动——先在电脑上启动程序，再回来点这个按钮。

Windows 安装与激活步骤

Install & activate
  1. 下载安装包并双击运行。
  2. 若出现蓝色 SmartScreen 画面：点「更多信息」→「仍要运行」（原因见上方说明）。
  3. 按安装向导走完，全程不需要命令行。
  4. 安装完成后 NiuxAgent 会自动启动，并在浏览器中打开。
  5. 按提示输入邀请码完成激活。
  6. 填入你自己的模型 API Key（选服务商、粘贴 Key）。Key 只保存在你的电脑上。
  7. 按页面提示把手机与电脑配对，即可开始使用。

手机端说明

On your phone
  • 安卓：在手机上下载 APK 后安装；系统会要求允许浏览器安装应用（因为试用版还没上架应用商店），装好后可以把这个权限关回去。然后打开 App，按提示与电脑配对。
  • iPhone：用 Safari 打开邀请消息里的网页应用链接，点「分享」→「添加到主屏幕」→「添加」，它会像普通 App 一样出现在主屏幕上，连接你电脑上的 Agent。
  • 顺序别反：先装电脑端并激活，再配对手机；手机端本身不单独运行 Agent。

系统要求

Requirements
  • 电脑：Windows 10 或更高版本（64 位），能正常联网；Agent 干活时电脑需保持开机（睡眠或关机时由云接力接应）。
  • 手机：安卓手机（装 APK）或 iPhone（Safari 网页应用）。
  • 模型：一个你自己的模型服务 API Key（多家服务商有免费额度可起步，用量在程序内可见、可设每日上限）。
  • macOS：暂无 Mac 版执行器；若有一台 Windows 电脑运行 NiuxAgent，可用 Mac 浏览器在同一局域网内配对后作为遥控界面使用。
遇到问题？邀请码不通过：检查粘贴时有没有多余空格，并确认用的是你本人邀请里的码（码与机器绑定、不可转借）。SmartScreen 找不到「仍要运行」：先点「更多信息」，按钮随后出现。其他问题发邮件到 support@niuxagent.com，注明卡在哪一步。更多见常见问题。
