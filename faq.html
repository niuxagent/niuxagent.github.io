FAQ

没找到答案？发邮件到 support@niuxagent.com。

试用要花钱吗？

不要。邀请试用期里 NiuxAgent 完全免费，云接力也包含在内。唯一可能的支出是你自己的模型用量：NiuxAgent 用你的 API Key 调用你选的模型，选了付费模型就直接付给那家服务商。多家服务商有足够起步的免费额度，程序内还能看用量、设每日上限。

邀请码怎么用？

先在 Windows 电脑上安装 NiuxAgent，程序打开后按提示输入邀请码即可激活。邀请码一人一码、与你的机器绑定，不要转借他人；粘贴时注意别带多余空格。邀请通过 Niux 频道与社区分批发放。试用期换了电脑，联系 support@niuxagent.com 帮你迁移激活。

激活失败怎么办？

先依次检查：① 码有没有输错或多了空格；② 用的是你本人邀请里的码（不是别人的截图或转发）；③ 电脑网络是否正常。还不行就把报错画面和卡住的步骤发到 support@niuxagent.com，我们帮你看。

我的数据存在哪？

只存在你自己的设备上。Agent 运行在你的电脑上，对话、文件和它的记忆都保存在那台电脑里。我们不接收、不在服务器上保存你的数据，不出售，也不用于训练模型。用云接力时，接力点也遵守同一规则：它只负责把任务转交给你的 Agent，不是存放你数据的地方。

模型 Key 怎么填？安全吗？

在安装引导（或之后的设置里）选好服务商，把你自己的 API Key 粘贴到专门的安全输入框里即可。Key 保存在你电脑上的受保护文件中，绝不打进聊天内容，机密文件也默认对 Agent 本身封存。服务商和 Key 随时可换。

什么是云接力？

Agent 住在你的电脑上，电脑关机或睡眠时它就联系不上。云接力是一个可选的值守服务：电脑不在时手机先联系接力点，电脑回来后两者自动交接。试用期接力由我们托管、免费；正式上线后，会员也可以把接力指向自己的服务器。

试用结束后会怎样？

NiuxAgent 转入正式发布。你的数据、设置和记忆都在你的电脑上，原样延续，不会被清空。本地 Agent 继续有免费版本；云接力和平台功能会开放可选会员。试用用户可以优先锁定创始档（见下）。

创始档是什么？

正式上线时的第一个会员档位：$19/年，限前 300 名，续费锁定 $19 不涨价。试用用户优先锁定。之后的档位依次是 $23/年、$26/年，标准价 $29/年。详见价格页。

支持哪些系统？

电脑端为 Windows 10 或更高版本。手机端有安卓 App；iPhone 试用期用网页应用（Safari 添加到主屏幕）。macOS 暂不支持。

怎么卸载？数据会怎样？

像普通软件一样在 Windows 设置里卸载即可。卸载程序不会动你的个人数据文件夹，重装后可以接着用。想彻底删除：卸载后再删掉 NiuxAgent 的数据文件夹——数据全在你本机，删掉即完全清除。

安装时 Windows 弹出蓝色警告画面，是中毒了吗？

不是。那是 SmartScreen 对未签名新程序的例行提示：试用版安装包目前还没有代码签名证书。点「更多信息」→「仍要运行」即可继续。说明见下载页。
