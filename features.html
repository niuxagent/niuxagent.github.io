Features

NiuxAgent 的设计只有一条主线：Agent 住在你的电脑上，为你干活，数据和决定权都留在你手里。

本机运行，数据不出设备Local-first

Agent 本体、对话记录、文件和记忆都存放在你的 Windows 电脑上。我们不接收、不转存你的数据，也不用于训练模型。卸载后想彻底清除，删掉数据文件夹即可，一切在你本机闭环。

长期记忆Long-term memory

它会记住你的偏好、正在推进的任务和上下文，跨会话延续。它还会把你反复做的流程沉淀下来，越用越顺手——这些记忆同样只存在你的电脑上。

自带模型（BYOK）Bring your own key

接入你自己选的模型服务、填你自己的 API Key，随时更换服务商或密钥，不用换程序。模型费用由你直接付给服务商，我们不加价；程序内可查看用量并设置每日上限，超限自动拦截并留痕。

手机遥控Phone remote

安卓用 App、iPhone 用网页应用：手机就是遥控器，发任务、看进度、点批准；真正执行的是家里或办公室里的那台电脑。

云接力Cloud relay

电脑睡眠或关机时，可选的云接力替它值守：手机先联系接力点，电脑回来后自动交回。试用期接力由我们托管、免费包含；正式版会员也可以把接力指向自己的服务器（BYOS）。

分级批准，安全边界清楚Approvals & safety

  • 日常操作：一键批准
  • 高风险动作：需要输入确认码
  • 密码与密钥：只走本地安全输入框，绝不打进聊天
  • 机密文件：按规则对 Agent 封存，默认读不到
  • 邮箱、日历等连接器：先只读，写操作要过确认拦截

技能系统Skills

能力以「技能」为单位扩展：出厂自带 9 件（每日简报、下载整理、电脑健康检查等），还能从内置技能商店继续安装。技能也可以由你自己的使用习惯沉淀生成——用得越多，它会的越多。

定时与主动提醒Scheduled & proactive

可以设定时任务让它按点干活（如每日简报），也可以让它在事情有变化时主动提醒你，而不是等你来问。

试用期形态：试用版通过电脑浏览器使用（网页形式）；发布版将提供原生软件窗形态。安卓 App 已就绪，iPhone 试用期用网页应用（添加到主屏幕），原生壳随后补齐。macOS 暂不支持。
